# Impact model — v1 (1 Nov 2026, rulings by Bekir; text: advisor)

Supersedes PLAN-v2 A8 "blow". Five impact types (+ scratch, added 2 Nov, unscheduled), three media, never mixed within a piece (A7).

## The record

Every event carries four medium-independent numbers; the type is a preset of them plus one verb.

```
{ t, type, energy 0–2, area 0–1, duration s, dir rad }
```

## The five types

| Type | Shape | Verb — what happens to matter | Notes |
|---|---|---|---|
| **drop** | point, instant | displaces locally | ring wave / crack / crater |
| **strike** | area, short | displaces widely | swell + splash / fissure + spalling / pit + thrown grains |
| **sweep** | directional, sustained, **with contact** | **absorbs**: matter along the path is lifted off the surface and **piles up at the sweep's edge** (ruling 09:52: it accumulates, it does not vanish) | layer below exposed along the path; the pile is matter of the removed layer |
| **blow** | directional, sustained, no contact | **pushes, as solids**: pieces move whole — grains, flakes, plates — they do not disappear; they pile where they land | piece size: **set by the medium, scaled by energy** (advisor's proposal 09:55; Bekir: "don't know") — sand: grains; solid: flakes → plates with energy; liquid: no pieces, surface only pushed (close to flow) |
| **scratch** (added 2 Nov 2026, 11:27, Bekir: "kazıma / scratch, sonra" — not yet scheduled) | directional, short-to-sustained, **hard point contact** (a nail, a stylus) | **cuts a thin furrow and pushes matter sideways**: a line as wide as the point, grains / swarf thrown to two lateral ridges, nothing absorbed, nothing lifted far (advisor's reading of the word; Bekir has not yet specified) | differs from sweep in width (a line, not a band) and in what happens to matter (displaced sideways, not drawn in); liquid: a wake line that closes behind the point; solid: a score line that later cracks prefer (ties to A4's relief steering); granular: furrow + two ridges, the furrow shows the layer below — the picture is written into |
| **flow** | directional, sustained | matter **flows**: liquid = current (image dragged, stretched); granular = slide down-slope in the flow direction; solid = creep/seep (slow, viscous, along cracks) | the only type where the image itself moves rather than being removed or covered |

## Per medium — which types mean something

| | drop | strike | sweep | blow | flow | scratch |
|---|---|---|---|---|---|---|
| liquid | ✓ | ✓ | ✓ (skims the film, exposes below briefly, pile = ridge) | ≈ flow | ✓ | ✓ wake line, closes |
| solid | ✓ | ✓ | ✓ (scrapes, pile = swarf at the edge) | ✓ (flakes/plates) | ✓ slow | ✓ score line (cracks follow it) |
| granular | ✓ crater + rim | ✓ wide crater + rim + thrown grains | ✓ (the natural one: grains drawn in, pile at the edge) | ✓ (the natural one: grains carried downwind, lee piles; **done in pass 3b-i**: band gust, stochastic hops, bed lift) | ✓ grains slide with the water | ✓ furrow + two ridges |

- *Für Alina* (piano) — drop; strike for the rare heavy chords. **Liquid medium (ruling by Bekir, 1 Nov 2026, afternoon).**
